# Reduce the burden of understanding and change

Prefer small interfaces that hide substantial complexity, local reasoning, and fewer sources of mutable truth. Optimize the final design, not the smallest patch on top of the old one. An extra implementation pass is worthwhile when it materially reduces complexity while preserving the agreed semantic and operational requirements. Deletion is useful when it removes obligations, not merely lines.

## Apply when

design, implement, simplify, review, deliver, rewrite
