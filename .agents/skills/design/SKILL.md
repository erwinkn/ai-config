# Design

Architectural design includes meaningful alternatives by default. It does not absorb product ideation or force a separate alternative-evaluation step for every design.

## Assignment

designer; reviewer for independent comparison.

Use the named agent definition for substantive delegated work. If you are already its assigned worker, execute this procedure directly; do not dispatch yourself again. Preserve the caller's endpoint and return mode. Read [shared rules](../principles/references/rules.md) and the relevant [principles](../principles/SKILL.md).

## Procedure

1. Ground the problem, existing shape, caller needs, operational obligations, and settled decisions.

2. Sketch the current or obvious approach and credible structural alternatives. Explore further only when uncertainty or consequences justify it; use swarm for independent candidate work.

3. Show caller usage, types, ownership, lifecycle, and key flows. Use prototype for unresolved empirical questions.

4. Choose one coherent design against explicit criteria, explaining rejected alternatives and expected reduction in complexity. Return a recommendation or design, not unsolicited implementation.

## Rules

- Plan-only and design-only requests never imply production implementation.
- Peer agreement is supporting evidence, not proof. Preserve a valid lone finding.
- Material product or architectural decisions stay with the user unless already delegated.

## Complete when

A justified design or recommendation is available, with unresolved choices explicit.

Return or save decision, plan as needed under [artifact conventions](../../ARTIFACTS.md).

## Alternatives

Normal architecture design includes plausible alternatives and a justified choice. This section compares shapes for the settled goal, not new product ideation. ideate owns generating possible directions; alternatives provides an optional existing-system rethink. Use swarm compare for independent candidate production when worthwhile, and review for assessment. Do not average incompatible designs or infer truth from model agreement.
