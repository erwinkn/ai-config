# Verification

Discover the primary user surface, launch command, readiness check, controllable interaction, observable outcome, evidence location, isolation, and cleanup. Build a project-local verify-<project> skill only when an existing recipe is inadequate. Name important user paths and prerequisites. Have an implementer write any small needed helper, then a verifier run a representative path and confirm the evidence survives cleanup. Maintenance compares source and live behavior without rewriting product regressions into the docs.
