# Clarify

One interviewing skill covers grill-me, grilling, and grill-with-docs. Recording domain decisions is composition with model, not a second interview procedure.

## Assignment

lead; designer may prepare choices.

Use the named agent definition for substantive delegated work. If you are already its assigned worker, execute this procedure directly; do not dispatch yourself again. Preserve the caller's endpoint and return mode. Read [shared rules](../principles/references/rules.md) and the relevant [principles](../principles/SKILL.md).

## Procedure

1. Read the available context and identify unresolved decisions, not every imaginable question.

2. Answer environmental facts through research. Ask a small set of currently answerable independent decisions, with a recommended choice when justified.

3. Record settled answers in the existing task artifact; invoke model when domain meaning changes.

4. Recompute the unanswered questions. Stop when the next step has enough agreed intent.

## Rules

- Never simulate the human’s answers or re-ask settled decisions.
- Synthesis of an already-agreed conversation proceeds without another interview.
- Dependent questions wait for their prerequisites; trivial reversible execution details do not block the user.

## Complete when

The blocking intent is settled, or a precise human decision remains pending.

Return or save plan, glossary, decision as needed under [artifact conventions](../../ARTIFACTS.md).

## Questionnaire

When another person holds the missing information, ask the user who the recipient is and what decision or facts are needed back. Draft questions for that gap, with enough background and a clear place to answer. Do not quiz the user about facts they already said they lack. Writing the questionnaire does not authorize sending it.
