# Explain

Explain to the human, rather than manufacture another investigation or a document on every turn.

## Assignment

lead; analyst for substantial technical synthesis.

Use the named agent definition for substantive delegated work. If you are already its assigned worker, execute this procedure directly; do not dispatch yourself again. Preserve the caller's endpoint and return mode. Read [shared rules](../principles/references/rules.md) and the relevant [principles](../principles/SKILL.md).

## Procedure

1. Use existing grounded findings; call research only for unanswered factual questions.

2. Explain the smallest complete mental model using the project vocabulary.

3. Add code references, a diagram, or an HTML walkthrough only when that representation helps.

4. For a confused response, reframe the explanation rather than repeating it with different jargon.

## Rules

- Preserve confidence qualifiers from the underlying evidence.
- A request for a normal explanation is not consent to a multi-session course or a large presentation.

## Complete when

The requested explanation is delivered in the appropriate format, with uncertainty retained.

Return or save research as needed under [artifact conventions](../../ARTIFACTS.md).

## Visuals

Choose a diagram, code-shape sketch, before/after comparison, or focused HTML page only when it improves understanding. Derive claims from the actual source or diff. Distinguish core behavior from mechanical changes in a PR walkthrough. Use the project vocabulary, retain uncertainty, and avoid generating large visual artifacts for simple questions. A teaching course or full presentation system is outside the default stack.

<a id="writing"></a>

## Writing

Use concrete mechanisms, meaningful names, complete sentences, and a document structure suited to its purpose. Cut formulaic introductions, repetition, empty enthusiasm, unexplained jargon, and performative persona language. Do not delete useful qualifications or articles to appear concise. Preserve the user’s requested tone for authored content. Exact punctuation bans, word blacklists, and decorative styles are personal preferences, not engineering laws.
